# Прожарка JS-проекта: увеличение производительности с помощью Rust

Продвинутый обучающий курс для разработчиков по глубокому разбору кода на JavaScript и изучению внутренностей браузера, на примере кодовой базы
[JoinSheets](https://github.com/JoinSheets/JoinSheets).

**Доступен только на русском
языке :((**

Подключён как git submodule к разделу «Учебный курс: Прожарка JS-проекта с помощью Rust» на официальной странице сайта организации
[JoinsSheets](https://joinsheets.github.io/).
