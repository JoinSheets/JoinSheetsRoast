# JoinSheets Roast: Rust Performance Boost Course

An advanced developer course on deep-diving JavaScript and browser internals,
using the [JoinSheets](https://github.com/JoinSheets/JoinSheets) codebase as
the worked example.

**Russian language only :((**

Builds and deploys as its own standalone Hugo + Compose site (GitHub Actions,
manual dispatch), separate from the main [joinsheets.github.io](https://joinsheets.github.io/)
site and its visual style -- live at
[joinsheets.github.io/JoinSheetsRoast/](https://joinsheets.github.io/JoinSheetsRoast/).
Linked from the main site's [Contributing](https://joinsheets.github.io/ru/docs/developers/contributing/)
page, not from its sidebar navigation.
