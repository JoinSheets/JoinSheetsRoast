# JoinSheetsRoast

Продвинутый обучающий курс для разработчиков по глубокому разбору кода на
JavaScript и внутренностей браузера, на примере кодовой базы
[JoinSheets](https://github.com/JoinSheets/JoinSheets). Только на русском
языке — учебный курс, не программный продукт, двуязычность сюда не
применяется.

Подключён как git submodule к разделу «Продвинутый курс» документации на
[joinsheets.github.io](https://joinsheets.github.io/).

**Статус: контент переносится из прежней версии курса (`ds-webui-review`) и
переписывается под новую кодовую базу и организацию — это placeholder-коммит,
собственно главы появятся следующим шагом.**
