Учебный курс по глубокому разбору кода на JavaScript и внутренностей браузера — на
примере небольшого проекта, написанного без
сборщика и фреймворков на ванильном JS.

Курс состоит из четырёх параллельных треков, идущих через каждую главу:

1. **Теория** — глубокие концепции программирования, основы компьютерсайнс и работы современных браузеров, с небольшими экскурсами в историю: откуда взялась та или иная идея, какую проблему она решала и как её заново изобретали в разных языках и фреймворках.
2. **Код** — каждая концепция из теории закрепляется разбором кода реального проекта: настоящий "грязный и живой" рабочий код, со всеми его компромиссами и отступлениями от канонов "best practice" там, где этого требует специфика.
3. **DevTools современного браузера** — попутно с разбором кода, глава за главой, осваиваем инструменты разработчика в браузере: от Sources и Console, до Performance и отладки WASM-модуля.
4. **Rust** — сквозная практика и финальный проект: переписать один из модулей проекта на Rust ради увеличения производительности и собрать для него биндинг через WASM.

По желанию, вы можете проходить эти треки параллельно и в полном объеме (рекомендуется), или взять лишь некоторые из них (например, теорию и разбор кода).

## Для кого этот курс

Курс рассчитан на продвинутую аудиторию: общий IT-бэкграунд и практика в программировании (JS, Rust, другие языки), знание основ веб-разработки (HTML, CSS), понимание внутренней работы браузера хотя бы на уровне интуиции. Ну и, конечно, желание разобраться глубже — и не просто прочитать, а получить практические навыки: понять концепцию отдельно от шума бизнес-логики, увидеть её живьём в реальном коде, потрогать руками инструменты разработчика, и, где возможно, переписать код по-своему.

## Формат обучения

Одна глава рассчитана на неспешное изучение в течении примерно одной недели:

| День | Что изучаем |
|---|---|
| 1 | Теория: концепция, зачем она нужна, какую проблему решает. В конце — раздел со ссылками на дополнительные источники по теме главы |
| 2-3 | Код: построчный разбор конкретных мест в проекте, где это используется |
| 4-5 | Практика: короткие упражнения (15-20 мин, формат быстрых заданий) — задания на понимание кода, упражнения в DevTools, перевод небольших сниппетов кода на Rust |

## Кодовая база

Для практических заданий учебного курса используется проект [`JoinSheets`](https://github.com/JoinSheets) — вьюер данных на JS с относительно небольшой кодовой базой (~4100 строк), которая лежит в репозитории [`https://github.com/JoinSheets/JoinSheets`](https://github.com/JoinSheets/JoinSheets).

Все ссылки на файлы/строки в этом курсе зафиксированы на:

```
commit <!!!>
version <!!!>
```

Если репозиторий проекта уйдёт вперёд — ссылки в этом курсе могут разойтись с актуальной версией. Ссылки не обновляются и не синхронизируются; при необходимости можно свериться с `git show
<!!!>:<файл>` в клоне `JoinSheets`.

## Технический стек и инструменты

Помимо языковой практики, курс рассчитан на изучение инструментов разработчика современных веб-браузеров. Чтобы к концу курса покрыть инструмент целиком, а не брейкпоинтами, каждая
глава вводит что-то новое:

| Глава | Новое в DevTools |
|---|---|
| 1 | Sources (файловое дерево), Console (инспекция объектов), Network, Overrides |
| 2 | Elements (живое дерево DOM, атрибуты vs свойства) |
| 3 | Sources: брейкпоинты, Scope/Watch, call stack |
| 4 | Node.js `--test` раннер (не DevTools) |
| 5 | Sources: Coverage (покрытие кода) |
| 6 | Elements: DOM breakpoints (break on subtree modification) |
| 7 | Sources: Scope panel (замыкания), Console `getEventListeners()` |
| 8 | Elements: вкладка Event Listeners, capture vs bubble |
| 9 | Performance (профиль, флейм-чарт, FPS) |
| 10 | Sources/Memory — отладка WASM-модуля |

Упражнения в DevTools читаются и выполняются с любого компьютера оснащенного любым современным браузером с поддержкой режима разработчика. Rust-упражнения — потребуют установленного компилятора Rust и IDE для работы с ним.

## Программа курса

| № | Тема |
|---|---|
| [01](01-bootstrap-without-bundler/) | Загрузка приложения без сборщика: `<script>`-теги, глобальный неймспейс, ES-модули |
| [02](02-dom-by-hand/) | DOM руками: `util.js::el()` — узлы, атрибуты vs свойства, обработчики |
| [03](03-state-and-reducer/) | Состояние и редьюсер: `store.js` — действия, чистые функции, `subscribe` |
| [04](04-testing-principles/) | Тестирование в JS, часть 1: принципы, `node:test`, что тестировать в `store.js` |
| [05](05-smoke-tests-fake-dom/) | Тестирование в JS, часть 2: смоук-тесты и паттерн fake-DOM |
| [06](06-render-without-vdom/) | Рендер без Virtual DOM: `main.js::render()` — полная перестройка поддерева |
| [07](07-closures-and-singletons/) | Замыкания и модульные синглтоны: `view-table.js` (`currentState`/`currentDispatch`) |
| [08](08-event-delegation/) | Делегирование событий и работа с DOM-событиями |
| [09](09-performance-and-event-loop/) | Производительность и event loop: батчинг рендера строк, Performance-профиль |
| [10](10-capstone-rust-wasm/) | Капстоун: `formula.js` → Rust + `wasm-bindgen` → WASM, замер прироста |

Опционный параллельный Rust-трек: короткое упражнение «перепиши код на Rust» почти в
каждой главе (кроме главы 1 — ориентационная, и главы 8 — браузерная
тема без аналогичного Rust-функционала), плюс капстоун главы 10.

## Режим обучения

Весь курс рассчитан на 10 недель обучения, в репозитории доступна первая версия. Проходится без
фиксированного срока и дедлайнов; уточнения, расширение теории под конкретные места и
донастройка упражнений — по запросу, по месту, в процессе прохождения.
