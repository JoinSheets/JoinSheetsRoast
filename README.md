# JoinSheetsRoast

An advanced developer course on deep-diving JavaScript and browser internals,
using the [JoinSheets](https://github.com/JoinSheets/JoinSheets) codebase as
the worked example. **Russian only** — this is teaching material, not a
product, and isn't translated.

Mounted as a git submodule under the "Advanced Course" section of
[joinsheets.github.io](https://joinsheets.github.io/).
