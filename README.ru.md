# JoinSheetsRoast

Продвинутый обучающий курс для разработчиков по глубокому разбору кода на
JavaScript и внутренностей браузера, на примере кодовой базы
[JoinSheets](https://github.com/JoinSheets/JoinSheets). Только на русском
языке — учебный курс, не программный продукт, двуязычность сюда не
применяется.

Подключён как git submodule к разделу «Продвинутый курс» документации на
[joinsheets.github.io](https://joinsheets.github.io/).

## Лицензия

Apache-2.0 — см. [LICENSE](LICENSE).

**Статус: все 10 глав перенесены из прежней версии курса (`ds-webui-review`)
как есть, с минимальной адаптацией под рендеринг сайтом (Hugo front matter:
`title`/`weight`). Полная переработка — замена упоминаний исходного
репозитория, перепроверка ссылок на код по актуальной кодовой базе
`JoinSheets`, привязка к релизу — отдельная, пока не начатая задача.**
