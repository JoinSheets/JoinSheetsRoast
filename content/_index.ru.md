# Прожарка JavaScript-проекта: увеличение производительности с помощью Rust

Продвинутый курс для практикующих веб-разработчиков.

Подходит тем, кто уже имеет опыт в программировании и хочет нырнуть глубже:

- погрузиться в кишки браузера,
- понять основы браузерной работы с памятью,
- освоить инструменты веб-разработчика,
- создавать высоконагруженные модули на Rust.

К концу курса Вы научитесь читать и понимать код и его работу «под капотом», находить «узкие места» производительности с помощью DevTools, проводить низкоуровневую оптимизацию и ускорять свои приложения с помощью Rust и WebAssembly.

Курс рассчитан на 10 недель самостоятельного изучения без жестких сроков и дедлайнов.
