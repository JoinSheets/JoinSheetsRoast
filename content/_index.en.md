An advanced developer course on deep-diving JavaScript and browser
internals, using a small project written without a bundler or frameworks
(plain, vanilla JS) as the worked example.

The course runs four parallel tracks through every chapter:

1. **Theory** — deep programming concepts and how modern browsers actually
   work, with brief detours into history: where an idea came from, what
   problem it solved, and how it got reinvented across different languages
   and frameworks.
2. **Code** — every concept from the theory is grounded in a walkthrough of
   real project code: genuine, "messy and alive" working code, with all its
   trade-offs and departures from "best practice" where the specifics call
   for it.
3. **Modern browser DevTools** — alongside the code walkthrough, chapter by
   chapter, covering the developer tools: from Sources and Console to
   Performance and debugging a WASM module.
4. **Rust** — a running practical thread and a final project: rewrite one of
   the project's modules in Rust for a performance gain and wire up a
   binding for it through WASM.

You can follow all four tracks in parallel (recommended), or pick just some
of them (theory and code, for instance).
