## Для кого этот курс

Курс рассчитан на продвинутую аудиторию: общий IT-бэкграунд и практика в
программировании (JS, Rust, другие языки), знание основ веб-разработки
(HTML, CSS), понимание внутренней работы браузера хотя бы на уровне
интуиции. Ну и, конечно, желание разобраться глубже — не прочитать, а
получить практические навыки: понять концепцию отдельно от шума
бизнес-логики, увидеть её живьём в реальном коде, потрогать руками
инструменты разработчика, и, где возможно, переписать код по-своему.

## Формат обучения

Одна глава рассчитана на неспешное изучение в течении примерно одной недели:

| День | Что изучаем |
|---|---|
| 1 | Теория: концепция, зачем она нужна, какую проблему решает. В конце — раздел со ссылками на дополнительные источники по теме главы |
| 2-3 | Код: построчный разбор конкретных мест в проекте, где это используется |
| 4-5 | Практика: короткие упражнения (15-20 мин, формат быстрых заданий) — задания на понимание кода, упражнения в DevTools, перевод небольших сниппетов кода на Rust |

Весь курс рассчитан на 10 недель прохождения без фиксированных сроков и
дедлайнов; уточнения, расширение теории под конкретные места и
донастройка упражнений — по запросу, по месту, в процессе прохождения.

## Кодовая база

Для практических заданий учебного курса используется проект
[`JoinSheets`](https://github.com/JoinSheets) — вьюер данных на JS с
относительно небольшой кодовой базой (~4100 строк), которая лежит в
репозитории [`https://github.com/JoinSheets/JoinSheets`](https://github.com/JoinSheets/JoinSheets).

Все ссылки на файлы/строки в этом курсе зафиксированы на:

```
commit <!!!>
version <!!!>
```

Если репозиторий проекта уйдёт вперёд — ссылки в этом курсе могут разойтись
с актуальной версией. Ссылки не обновляются и не синхронизируются; при
необходимости можно свериться с `git show
<!!!>:<файл>` в клоне `JoinSheets`.

## Технический стек и инструменты

Помимо языковой практики, курс рассчитан на изучение инструментов
разработчика современных веб-браузеров. Чтобы к концу курса покрыть
инструмент целиком, а не брейкпоинтами, каждая глава вводит что-то новое:

| Глава | Новое в DevTools |
|---|---|
| 1 | Sources (файловое дерево), Console (инспекция объектов), Network, Overrides |
| 2 | Elements (живое дерево DOM, атрибуты vs свойства) |
| 3 | Sources: брейкпоинты, Scope/Watch, call stack |
| 4 | Node.js `--test` раннер (не DevTools) |
| 5 | Sources: Coverage (покрытие кода) |
| 6 | Elements: DOM breakpoints (break on subtree modification) |
| 7 | Sources: Scope panel (замыкания), Console `getEventListeners()` |
| 8 | Elements: вкладка Event Listeners, capture vs bubble |
| 9 | Performance (профиль, флейм-чарт, FPS) |
| 10 | Sources/Memory — отладка WASM-модуля |

Упражнения в DevTools читаются и выполняются с любого компьютера оснащенного
любым современным браузером с поддержкой режима разработчика.

Опционный параллельный Rust-трек: короткое упражнение «перепиши код на Rust»
есть почти в каждой главе (кроме главы 1 — ориентационная, и главы 8 —
браузерная тема без аналогичного Rust-функционала), плюс капстоун главы 10.

Прохождение Rust-трека потребует установленного компилятора Rust и IDE для
работы с ним.
